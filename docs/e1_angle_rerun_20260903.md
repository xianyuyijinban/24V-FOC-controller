## 2. 定性（E1 案定论）

### 2.1 角度链无 bug（V2 门核心结论）
- 轴锁死 + 低档全同相（Iq 主导，夹角 4-14° 随 Vq 收敛到纯阻）——欧姆定律预期满足
- 角度链代码调查（注入链/测量链同一 `foc.sin_theta/cos_theta`，θ_elec=θ_mech×enc_dir×Pn+θ_offset，与 vfoc 分支 95ac679 逐字符相同）→ 结论"一致且正确"，复跑确认
- **"负载角 90° 正常物理"叙述弃用**（那是概念误用：堵转 ω=0 纯阻必同相，非假设）

### 2.2 E1 原始病样根因 = 手限位不理想（转子被拖转）
- 第一次复跑（轴可转）500mV PASS 3.9° 其余乱转 → 转子被电压拖至不同齿槽平衡点，电流矢量随转子位置转（≈轴转×Pn 电角）
- 第二次（轴锁死）低档全 PASS——病样随锁死消失
- **结论: E1 原始 90° 错位是测量条件（限位不良），非固件 bug**

### 2.3 新发现: 高档堵转磁偏转（≥1V）
- 轴锁死但 1.0/1.5V 档 d-q 双极增长（Id -85→-266mA, Iq -213→-204mA）——堵转大电流非线性（磁饱和/电压分配偏转）
- **线性模型仅 0.2-0.5V 档成立**；S2 控制律注意 ≥1V 段非线性
- 这个现象部分解释了 E1 原始 commit"负载角 90°"的观察（大电流档电压矢量偏移），但只在 ≥1V 出现

## 3. Rs/死区标尺（S1.2 顺带）

- **低档 Rs=4.5Ω（拟合）/5.2Ω（导纳）** = 相电阻口径（线线 8.8/2=4.4 冷态 + 微发热）——口径闭环，见 RS 口径记忆
- **死区压降 V0=43mV（20kHz）**：低于 E4 的 200-300mV（10kHz 时代）——**载波翻倍死区有效值下降预期一致**（20kHz 死区占比减半）
- 但 43mV 低于理论 150mV DT 补偿默认——需确认是否斜坡/测量窗误差；正式标定留 S2 前（DT 幅值候选 100-150mV）
