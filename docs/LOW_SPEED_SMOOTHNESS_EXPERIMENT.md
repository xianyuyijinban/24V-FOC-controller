# 低速平滑性优化实验 — 设计文档与状态跟踪

> 目的：解决电机低速转动不平滑（齿槽+摩擦导致），为云台/关节电机低速应用验证架构与补偿方案。
> 状态跟踪：本文档是唯一主记录，任何实验结论/参数定版先更新此文档。

## 1. 背景与问题

- 电机低速转动不平滑（"一顿一顿"），齿槽转矩 + 摩擦（静摩擦+粘滞）叠加导致。
- 目标应用：云台慢摇（0.02~0.1 rad/s）、关节电机（低速段+零速穿越）。
- 低速域速度估计信噪比差 → P-only 速度环扰动抑制弱。

## 2. 已完成发现（2026-08-13/14 台架实测）

### 2.1 架构判别：位置环直连电流环（POS_DIRECT）显著改善稳态抖动

| 指标 | CASCADE(级联) | DIRECT(直连) | 改善 |
|------|--------------|--------------|------|
| 位置纹波 angle_pp | 6.83° | 2.10° | **-69%** |
| 力矩纹波 iq_pp | 0.0174A | 0.0139A | -20% |

- 直连结构跳过速度环PI（低速速度信号不可靠），位置环PD输出直接作为力矩指令。
- **修正解读**：该改善是"稳态抖动"维度；"能否快速到位"两结构都受摩擦限制（见 2.4）。

### 2.2 直连增益调优（定版 kp=0.5, kd=0.03）

- 扫参结论：**kd 越大位置纹波越差**（kd=0.03 一致最优）→ 低速速度差分噪声经 D 项放大。
- 定版：`kp=0.5 A/rad, kd=0.03 A/(rad/s)`，angle_pp=1.361°，iq_pp=0.0109A。
- 注意：定版值**尚未写入固件默认**，当前默认 kp=1.0/kd=0.03。测试用 `CMD:POS_DIRECT_GAIN` 运行时设。

### 2.3 齿槽 LUT 评估（当前是负优化）

- COG ON(gain=0.25/phase=60°) 比 OFF 位置纹波恶化 28.6%（1.719° vs 1.337°，n=3）。
- 相位扫描：+120° 优于默认 60°（1.432° vs 2.005°），但跨轮波动大。
- **结论**：当前 LUT 需专门标定（相位对齐 + 多转重采 + 谐波滤波），步进序列对 COG 检测不灵敏。作为独立优化项。

### 2.4 摩擦特性量化（关键输入）

- 力矩模式 IREF 递增测启动电流（克服静摩擦+齿槽）：**正向 +0.08A，反向 -0.10A，平均 ~0.09A**。
- 位置环爬行根因：位置环给 ~0.08A 力矩（iq_ref），但实际 iq_act≈0.02A，在启动阈值边缘。
- 现有静摩擦补偿（速度 0.03A / 位置 0.05A）**远低于实测 0.09A**，低速时补偿被静摩擦完全吃掉。
- **低速不平滑根因 = 静摩擦(≈0.09A) + 齿槽转矩叠加**。结构切换改善抖动，未解决摩擦本身。

### 2.5 技术坑记录（防再踩）

- **UART 流式命令 PC 端 write 阻塞**：单线程连续 `ser.write` 命令流致 N 帧采集骤降至 ~2fps。
  解决：后台线程发命令 + 主线程读（见 speed_ramp_test.py）。所有流式命令脚本必须如此。
- **位置环最短路径语义**：PREF 递增超 360° 触发 `FOC_AngleNormalize` wrap，目标来回跳。
  匀速测量限单圈扫动（SWEEP_RAD=1.0 rad）。
- **FOC_STATE 枚举**：IDLE=0,INIT=1,PARAM_IDENTIFY=2,READY=3,RUNNING=4,FAULT=5（state=4=RUNNING）。

## 3. 当前实验：静摩擦补偿力矩扫描

### 3.1 问题

现有静摩擦补偿为编译期宏 bang-bang 固定 0.05A，低于实测 0.09A。需验证：**不同力矩补偿电流下，低速到位速度/稳态稳定性/平滑性哪个最优**。

### 3.2 实现（固件改动）

- 运行时摩擦补偿变量 `fric_comp_pos / fric_comp_neg`（A，替代编译期宏 `FOC_POSITION_USER_*_STATIC_FRICTION_COMP_A`），默认 0.05A。
- 命令 `CMD:FRIC_COMP,pos,neg` 设置；`CMD:FRIC_COMP?` 查询。
- 补偿仍为 bang-bang 形状（误差>3°进/误差<1°退），但幅值运行时可调。

### 3.3 实验变量与序列

- 补偿电流 ∈ {0, 0.05, 0.07, 0.09, 0.11, 0.13} A（覆盖实测阈值 0.09A 两侧）。
- 结构：DIRECT，kp=0.5/kd=0.03（`CMD:POS_DIRECT_GAIN,0.5,0.03`），COG OFF。
- 每档测试：
  1. PREF +6° 步进：测 0.5s/1s/2s 后到位角度 → 到位速度
  2. 到位后 2s 稳态：角度抖动（p-p）、是否过冲/漂移
  3. PREF -6° 步进同样测（反向对称）

### 3.4 判据

- **最优**：到位快 + 无过冲 + 稳态稳（抖动小、不漂移）。
- 补偿过大 → 滑跑/过冲/稳态振荡；补偿过小 → 爬行/停顿。
- 观察正反向对称性。

### 3.5 脚本与数据

- 脚本：`scripts/friction_comp_sweep.py`
- 数据：`scripts/friction_comp_sweep_*.json`（每档到位时间曲线 + 稳态统计）

### 3.6 扫描结果（2026-08-14 实测）

| 补偿A | 正向1s剩% | 反向1s剩% | 稳态pp° | 过冲° |
|-------|-----------|-----------|---------|-------|
| 0.00 | 96.0 | 77.5 | 0.025 | 5.43 |
| 0.05 | 76.2 | 71.3 | 0.020 | 5.06 |
| 0.07 | 55.8 | 64.8 | 0.030 | 5.49 |
| 0.09 | 35.0 | 22.3 | 0.020 | 5.27 |
| 0.11 | 34.8 | 21.8 | 0.030 | 3.80 |
| 0.13 | 31.5 | 21.2 | 0.030 | 3.40 |

**结论 1（验证）**：补偿越大到位越快，0.13A 最优（正向 1s 剩 31%，反向 21%）。实测启动电流 0.09A 位于拐点，**0.11~0.13A 为最优区间**。静摩擦补偿方向成立。

**结论 2（新问题）**：6° 阶跃**过冲普遍 3~5°（60~90% 超调）**，且 0A 补偿时也有 5.4° → **非补偿造成，是 DIRECT kp=0.5/kd=0.03 阶跃阻尼不足**。低速稳态优化（kd 小）与大步进阻尼需求矛盾。
- 云台慢摇为小幅斜坡场景，阶跃过冲影响待真实场景评估；但系统阻尼弱是客观问题。
- 候选：加大 KD（牺牲一点稳态）、斜坡生成器替代阶跃、或增加位置环阻尼项。

### 3.7 阶跃过冲根因定位（2026-08-14 实测：KD 扫描 + 斜坡验证）

**假设**：A) 加大 KD 压过冲（阻尼）；B) 斜坡替代阶跃可避开过冲（云台真实场景）。

**实验 A：KD 扫描**（kp=0.5 固定，补偿 0.12A，±6° 阶跃）

| kd | 1s剩%均值 | 稳态pp° | 过冲均值° |
|----|-----------|---------|-----------|
| 0.03 | ~25 | 0.020 | 3.65 |
| 0.06 | ~24 | 0.025 | 4.98 |
| 0.09 | ~22 | 0.025 | 3.90 |
| 0.12 | ~20 | 0.035 | 4.77 |
| 0.15 | ~17 | 0.025 | 5.43 |
| 0.20 | ~11 | **0.145** | 5.29 |

- **加大 KD 压不住过冲**（全程 3.6~5.4° 不降），稳态却恶化（0.20 时 pp 0.02→0.145）→ **排除"加大 KD"**。

**实验 B：斜坡命令**（后台线程发 2°/s 斜坡 PREF，kp=0.5/kd=0.03，补偿 0.12A）
- 前 1s 位移≈0（爬行），斜坡结束（3s）只到 4.5/6°，**末端差 1.4~1.7° 追不上**。
- 反向轨迹呈典型粘滑：-1.5° 卡住 → 2.4s 突跳 -3.5° → 回弹 -2.9° → 稳定 -4.3°。
- → **PC 端斜坡没解决过冲，反而暴露更严重的跟踪滞后 + 粘滑**。

**根因（阶跃过冲与斜坡滞后同源）**：
- P-only 位置环对静摩擦有固有稳态误差：P 项要突破 0.09A 需误差>10.3°（kp=0.5）。补偿退出后平衡点可离目标 ~10°。
- bang-bang 补偿死区（误差>3°切/1°退）慢速斜坡下失效：跟踪误差恒<3° → 补偿从不触发 → P 项<静摩擦 → 粘住；误差过阈值补偿突切入 → 粘滑+过冲。
- **云台慢摇=极慢斜坡，误差恒小 → 现有补偿方案真实场景会卡死，必须固件重构。**

**结论**：低速摩擦补偿需重构。候选：①位置环加积分（PI，消除稳态误差）；②补偿从"误差死区"改"速度方向相关"（PREF 在变即补满，连续输出）；③摩擦观测器（后续）。维持 kp=0.5/kd=0.03 定版不变。

### 3.8 固件重构方案（低速静摩擦，2026-08-14）

**实现状态**：已实现于 `foc_app.h/c` + `stm32h7xx_it.c`（GCC 编译 0 错 0 警），Keil 烧录 + pyOCD reset 后台架验证通过。

**验证结果（对比旧固件，2026-08-14 实测）**：

| 指标 | 旧固件 | 新固件 |
|------|--------|--------|
| 6° 阶跃过冲 | 3.8~5.4° | **0.58°** |
| 6° 阶跃到位 | 1s 剩 35% | **0.5s 到位 100%** |
| 斜坡 2°/s 末端差 | 1.4~1.7° 追不上 | **3s 到位，超调 +0.5°** |
| 斜坡前 1s | 完全卡住（爬行） | **0.5s 走 0.6°，无爬行** |
| 稳态 pp | 0.02~0.03° | 0.03~0.08° |

- **结论**：方向锁存连续补偿消除慢速斜坡爬行/滞后；直连 PI 消除阶跃过冲。低速位置控制两个核心问题均解决。
- 注：斜坡汇总"过冲 6°"是 summarize 把起点位移 0 计入 `|0-6|` 的统计 bug，真实超调 0.5°。

**遗留（下一步优化）**：反向略差（斜坡反向 3.2s 到位、阶跃反向剩 27%、过冲 3.28°）——静摩擦/齿槽正反向不对称。

**技术坑补充**：pyserial 同一句柄并发 write/read 会饿死读（斜坡后台持续写期间 0 帧，停写即恢复）。流式命令脚本必须**单线程交替**（每 0.2s 发一步 + 读），不可后台线程持续写。

### 3.9 Phase A：低速匀速优化进展（2026-08-14）

**最终最优配置（2026-08-15 确认）**：固定 kp=2.0（运行时 `POS_DIRECT_GAIN,2.0,0.03`）+ FF库仑 Tc/Kt 前馈（Stribeck 平滑 + pos_cmd_dir 低速方向兜底）+ comp=0 + ki=0。
**匀速 2°/s**：速度均值 1.73°/s（86%），角度残差 pp 3.9° / std 0.98°，速度 std 2.26（含编码器 12bit 量化 ~1°/s）。

**已尝试未采纳**：
- **变速增益（非线性刚度）**：误差大→低 kp 防过冲、误差小→高 kp 跟进。实测匀速反而恶化（0.99°/s，kp 实时变化引入增益调制扰动），**已回退**。需 kp 滤波后重试，或放弃。
- **fric_comp 0.12 替代 Tc/Kt**：匀速过补偿振荡（-1.14°/s），回退 Tc/Kt。

**目标**：云台慢摇真实场景 = 极慢匀速跟踪（0.1~2°/s）。摩擦重构后阶跃 OK，但匀速 2°/s 严重粘滑（速度均值仅 0.82°/s，残差 18.6°）。

**根因定位链**（`CMD:DIR?` 诊断命令决定性定位）：
1. **补偿方向反**：`pos_ref` 是 control frame（=用户角×encoder_dir），encoder_dir=-1 时用户角递增→control 角递减→`ref_delta` 符号反 → 补偿与运动反向（匀速粘滑 + friction 正反向不对称的根源）。修复：锁存/清方向乘 `encoder_dir_f`。
2. **FF 库仑前馈死区**：`FOC_FF_COULOMB_DEADBAND_RADPS=0.05`，2°/s(=0.035) 恰好低于死区 → 低速库仑前馈从不触发 → 爬行。修复：低速用指令方向兜底（`pos_cmd_dir`），Tc/Kt 连续输出。
3. **Stribeck 平滑**：库仑前馈随速度指数衰减（起动满静摩擦→匀速衰减到动摩擦），消除 bang-bang 振荡。
4. **pos_cmd_dir 独立补偿禁用**：与 FF 库仑双份时过补偿（匀速 1.8→1.25°/s 恶化）。

**匀速 2°/s 结果链**：

| 配置 | 速度均值 | 残差 pp |
|------|---------|---------|
| 初始（kp=0.5+补偿0.12） | 0.82°/s | 18.6° |
| kp=2.0 | 1.58°/s | 4.46° |
| +Stribeck | 1.24°/s | 3.73° |
| **+FF库仑Tc/Kt兜底（comp=0）** | **1.81°/s** | **2.94°** |

- 速度 0.82→1.81°/s（90% 目标），残差改善 6 倍。
- 剩余速度 std ~2.3：编码器量化（12bit 差分 ~1°/s）+ 22 次/圈磁阻力矩（0.036A）+ 齿槽（0.007A，次要）。
- **齿槽 LUT 标定**（cogging_calibrate.py）：波形 pp=0.123A，**主导 22 次/圈**（22P 电机磁阻/极谐波，非理论齿槽 24）。LUT 相位对齐受 theta_mech vs 用户角 offset 限制，未稳定改善 → 待精确对齐或改速度观测器。
- **阶跃 vs 匀速矛盾**：comp=0 匀速好/阶跃起动慢；comp=0.12 阶跃好/匀速过补偿振荡。**当前取 comp=0 + kp=2**（阶跃靠 PD 大）。

**剩余差距（商用云台对比）**：速度纹波 std/mean ≈ 128%（云台 <5%）。直连架构无速度环，低速匀速受静摩擦非线性限制。**要突破需速度环 + 观测器**（商用方案）。

### 3.10 真实场景慢摇验证（2026-08-15）—— 极低速 0.1°/s 是架构硬伤

**云台慢摇真实场景（0.1~0.5°/s）三种方案实测**：

| 方案 | 0.5°/s | 0.1°/s |
|------|--------|--------|
| 位置环直连 + FF库仑 Tc/Kt(0.06) + Stribeck | **92%（0.46°/s），残差std 0.91°** ✅ | 爬行（40% 停顿，0.07°/s）|
| 位置环 + fric_comp(0.12) + Stribeck(极低速固定满) | -0.37°/s 反向振荡 ❌ | 振荡（-0.14~+0.39°/s 来回）|
| 速度模式（SREF=0.1°/s）| — | 15%（0.015°/s）→ 修复积分阈值后仍 -0.034°/s 反向 ❌ |

**速度模式积分阈值修复尝试**：根因一度定位为 `abs_sref<0.02f` 清积分（0.1°/s=0.0017 被清）。下调到 0.0005 后实测仍失败（反向 + 42% 停顿）——**速度估计噪声 ±0.5°/s 淹没 0.1°/s 信号，速度环信噪比太差**，积分不是主因。阈值下调保留（无害，为观测器后速度模式铺路）。

**结论**：
- **0.5°/s 是当前架构实际可用下限**（92% 跟踪，残差 0.9°）。
- **0.1°/s 极慢摇全部方案失败**：位置环补偿过冲/爬行死区（静摩擦 0.09 vs 动摩擦 ~0.03，固定补偿不匹配）；速度模式速度估计噪声淹没信号。
- **要贴近商用云台（0.1°/s 平滑）必须速度观测器**（平滑速度估计 + 速度环），这是云台算法的核心工程，现有 P4 Gopinath 观测器（FOC_FF_ENABLE_OBSERVER=0）可扩展。
- 当前固件 = 0.5°/s 最优（FF库仑 Tc/Kt + Stribeck + comp=0 + kp=2）+ 速度环积分阈值 0.0005。

### 3.11 速度观测器（线性ESO，2026-08-15 实现，待台架验证）

**根因回顾**：0.1°/s 时位置每速度环周期移动 0.00005°（15bit LSB 的 0.005），直接差分原始噪声 ±22°/s，20Hz LPF 后 ±0.5°/s 淹没信号。这是**分辨率限制**，滤波调不动。

**设计**（调研定稿：增广 Luenberger = 线性 ESO，文献 Lorenz 1991 低速量化噪声抑制 / Solsona 2000 扰动估计）：
- 状态 [θ, ω, T]（全部机械帧），模型 `J·dω/dt = Kt·Iq − B·ω − T`，T 为慢变聚合扰动/摩擦
- 极点配置三重极点 −ω0：L1=3ω0−B/J, L2=3ω0²−L1·B/J, L3=−J·ω0³
- **ω0 双边界**：上限量化噪声 σ_ω≈σ_q·ω0（ω0=15 时 ~0.05°/s），下限覆盖位置更新率（0.1°/s→0.11s/LSB→ω0≳10）。**初值 12 rad/s**，ω0>30 重新淹没、<8 扰动收敛慢
- 低速时 ω_hat 由模型积分主导，位置仅在跨越 LSB 时轻校正 → 平滑速度

**关键实现决策**：
1. **驱动用实测 Idq.q × encoder_dir**（转机械帧）：现有 Gopinath DOB 门禁 enc_dir==+1 正是符号问题；且用实测非指令，避免"指令自洽"陷阱
2. **T_hat 限幅(0.03 N·m) + 限速率(0.05 N·m/s)**：慢变扰动不被单拍残差冲击
3. **本轮 T_hat 只留在观测器内吸收模型误差，不做前馈输出**（避免与 Stribeck 库仑双重补偿）；平滑速度验证后再让 T_hat 平滑替代
4. J/B/Kt 用辨识值（motor_param.J/B/Ke），fallback 保护
5. **接线**：观测器更新在 2kHz 速度环 FF 层尾（SetCurrentRef 后）；POS_DIRECT D 项经 `obs_use_d` 可选切观测器速度（平滑 D 允许更高 kd）

**台架验证结果（2026-08-15）**：
- **观测器工作正常**：0.5°/s 匀速（级联）omega_hat std **0.53°/s** vs 差分 **2.00°/s**（平滑 **73%**）

- **关键坑（离散增益，台架实测定位）**：连续极点增益 L1=3w0 直接用于 2kHz 前向欧拉离散会**发散**（omega_hat 爆到 3e5°/s）。离散校正增益**必须乘 Ts**：`L1=3w0·Ts, L2=3w0²·Ts, L3=−J·w0³·Ts`（离散极点 z0=e^{−w0·Ts}）

### 3.12 迭代2：速度环反馈切观测器 + T_hat 前馈（2026-08-15）

- diff std 1.2°/s、omega_lpf std 5.5°/s（仍有抖动，增益窗口窄待精调）

**里程碑**：观测器让 0.1°/s 速度闭环从不可行变可跟踪；但平滑度（纹波 <5%）仍需：T_hat 前馈增强、增益窗口精扫、齿槽前馈。

### 3.14 T_hat=0 深挖根因链（2026-08-16）

**现象**：观测器 T_hat 在速度/位置模式恒为 0，T_hat 前馈从未真正生效（速度模式 63% 是速度环积分硬扛达到的）。

**根因链（逐层排除后定位）**：
1. **原算法（L3 位置残差学习）不可观**：低速位置量化残差零均值随机游走，对恒定摩擦无系统性分量可学；放大 L3（t_gain）只会 T→ω 反馈振荡（实测 t_gain=50 → omega std 12.9°/s），T_hat 仍 0。
2. **改 DOB（T=Kt·Iq−J·dω/dt）后观测器稳定**（omega std 12.9→0.75），T_hat 非零但极小。
3. **真正根因**：DOB 依赖**实测 Idq.q**，而低速小电流时 **Idq.q≈0**（实测：位置模式电机走 1.31° 但 Iq mean −0.0007A）。电流采样分辨率/噪声使低速摩擦电流（0.03-0.09A）在 Idq.q 里不可见 → T_dob=Kt·Iq≈0 → 学不到摩擦。

**结论**：
- 观测器**速度估计（omega_lpf）正常**（基于位置，不依赖 Iq）；**T 估计两条路都堵**（位置残差不可观 + 实测电流≈0）
- 位置模式 77% 靠 **FRIC_COMP 先验摩擦前馈**（0.09A 匹配启动电流），不依赖 T_hat——这是低速摩擦补偿的**可靠路径**
- 速度模式 0.1°/s 摩擦前馈难：死区（0.05 rad/s > 0.1°/s）+ Tc=0 无先验

**下一步方向**（T 前馈要工作，二选一）：
- **指令 Iq + Q 滤波**：T 用 Iq_ref（连续可靠，非采样）但需处理前馈正反馈（Q 滤波器/前馈解耦）
- **先验摩擦**：识别 Tc 或速度模式复用 FRIC_COMP，摩擦前馈不用观测器 T_hat

### 3.15 先验摩擦前馈（方案 B，2026-08-16）

**实现**：速度模式摩擦前馈统一用 **FRIC_COMP 先验**（替代 Tc/Kt=0）+ **SREF 指令方向兜底**（低速差分速度噪声不可靠，高速仍用速度方向）+ **Stribeck 平滑用观测器速度**（omega_lpf，差分噪声使 smooth 波动）。

**实测**：
- **方向正确**：comp=0.15 纯前馈（Kp≈0）→ 正向速度 0.27°/s；comp=0.09 不够起动（当前齿槽/静摩擦启动电流 >0.09A）
- **速度模式 0.1°/s 闭环仍不稳定**：comp 0.09 + obs_use_speed + kp 0.08 → 起动反向 + 振荡（-52%），速度 mean 正（+0.42°/s）但角度净负——**前馈/反馈竞争**（前馈过驱动 → 速度环反向抑制 → 振荡）
- **差分反馈 0.1°/s 反向根因**（无观测器）：差分噪声 ±0.5°/s > 0.1°/s 信号，速度误差符号被噪声主导 → 必须观测器反馈

**结论**：
- 先验摩擦前馈**方向/起动验证成功**，但速度模式低速闭环（前馈 + 反馈 + 观测器）难调稳——前馈幅值、Stribeck 衰减、速度环增益三方竞争
- **0.1°/s 位置模式 77%（comp 0.09 + 位置环 + 条件积分）是当前唯一稳定可靠路径**——位置环提供阻尼使前馈不振荡
- 速度模式 0.1°/s 需更深度控制器设计（前馈解耦：前馈不进速度误差、Q 滤波、观测器前馈分离）

**Stribeck 校准验证（3.15 续）**：Stribeck 参数运行时化（`CMD:FRIC_CFG,<vs>,<kin>`），校准 vs=0.001 让运动时前馈衰减到动摩擦（0.12A→0.037A），实测**仍反向振荡**（std 12°/s，smooth 对速度噪声更敏感）。**结论：速度模式 0.1°/s 摩擦前馈是结构性负优化**——前馈与低速速度环竞争（过驱动→反向抑制），与 Stribeck 参数无关。**速度模式 0.1°/s 最佳 = 观测器反馈 + 无摩擦前馈（63% 正向，速度环积分+观测器平滑）**；摩擦前馈在此场景负优化，仅位置模式受益（位置环阻尼）。

**下一步**：增益窗口精扫（Kp 0.05-0.08 步进）；T_hat 幅值校准；或 0.1°/s 位置模式 + 观测器 D 项（pos_direct + obs_use_d）替代速度模式。

### 3.16 电流环健康度排查（2026-08-16）—— 电流环只交付 ~20% 指令电流

**起因**：怀疑 "Idq.q≈0@低速" 是 θ_elec 错位。先纠正一个字段误读：上次 "Id=+5.45A" 是脚本把 N 帧 `p[4]=speed` 误读成 Id，真实 Id=+0.011A（正常）。**撤销 θ_elec 错位警报。**

**排查过程**（脚本 `_diag_current_loop.py` / `_diag_adc_phase.py` / `_diag_pwm.py`，COM10@1M）：
1. **N 帧字段确认**（`uart_upload.c:398`）：`p[3]=angle(°) p[4]=speed p[5]=Id p[6]=Iq ... p[16]=Id_ref p[17]=speed_ref p[18]=pos_ref p[19]=Iq_ref p[20]=Vd p[21]=Vq p[22-24]=Ia/Ib/Ic`。
2. **力矩 IREF(0,0.30) 电机起转**（speed +5.74°/s）但 Vq=+0.63V、实测 Iq≈+0.004~0.05A —— 指令 0.3A 只交付 ~20%。
3. **ADC_PHASE_SCAN 扫触发点**（2-46）：raw ADC 恒≈偏置（A≈2052/B≈2062/C≈2067），一度误判"电流测量冻结"。**实为 FAULT 停转态**（见 5）。
4. **清故障重使能后**：PWM_DIAG 显示 Vq=630mV、Vqpi=157mV、Iq=±50mA 随运行波动 —— **电流测量活着且读数正确**。

**根因（高置信）**：电流环为 **P-only（Kp=0.5, Ki=0）+ RsFF scale=0.20**，对高阻电机（**Rs=8.8Ω**，76KV 实测）**欠驱动**。推导：
- `Vq = Kp×(Iq_ref−Iq) + 0.2×Rs×Iq_ref = 0.5×0.3 + 0.2×8.8×0.3 = 0.15+0.53 = 0.68V`（实测 0.63V ✓）
- 真实电流 = Vq/Rs ≈ **0.07A**（指令 0.3A 的 ~23%）
- P-only 无积分，误差恒在 → 永远达不到指令。

**关键事实**：
- `rs_ff_scale` 从 1.0（全幅 Rs 前馈, c328c4d）**有意降到 0.2**（bfb0fdd, 2026-06-22，post-ARR baseline：±1 rad/s 速度模式扫出 Vq pk 26-51mV，0.30 有零回残留）。
- 电流环增益全程小（Kp 0.3→0.5, Ki 0.1→0）：**这是长期既定基线，非新回归**。
- **系统在 "IREF 单位" 下自洽**：位置/速度环、摩擦补偿全部按弱交付校准 → 77%/63%/73% 结果仍有效；真实电流 ≈ 0.23×IREF。
- **连锁解释**：T_hat=0（DOB 用实测 Iq≈0.02A→Kt×Iq 极小）；"Idq.q≈0" 是真实小电流，非分辨率瓶颈；t3-a2 "Iq 10×短" 同源。

**偶发故障**：`ENABLE,FAIL,fault=7`（FOC_FAULT_ADC_SAMPLING）—— `ADC_Sampling_TryConsumeLatest()` 帧超时累计触发。**相位扫描把 TIM1 CH4 触发点扫到 2-46 可能诱发**（恢复 10800 后清故障即好）。诊断时避免在运行中改触发点。

**决策点**（方向二选一，影响所有调参尺度）：
- **A. 修复电流环交付**：rs_ff_scale→1.0 或加 Ki，电流交付 ~5×，但**所有 IREF 单位的摩擦/增益需重标**（改动大）。
- **B. 接受弱交付基线**：在 IREF 单位继续（0.1°/s 位置 77% 路径），T_hat 前馈不指望。

| **0.5°/s** | ~40% | ❌ 电机**卡死**（误差恒 +12°，角度纹丝不动）|
| **2°/s** | 81-84% | ✅ 不错 |

**0.5°/s 卡死机制**：误差累积到 +12° 后电机不再响应——kp×12°≈0.10A 指令 + comp 0.022，理应驱动（摩擦 0.025A），但电机保持不动。非粘滑（无突跳），是**对驱动的持续不响应**。诊断：角度恒 0.3°、误差恒 +12.2°（std 0.27°）。

**已尝试全部杠杆均未突破 0.5°/s（~40% 封顶）**：
- ki 0.2-1.5：46-53%→38-44%（修 bug 后）
- comp 0.022-0.10：19-53%（>0.05 过补偿振荡）
- Stribeck vs/kin 组合：30-50%
- 观测器 D 项 + kd 0.03/0.05：39-46%

**FF 库仑澄清**：代码已改 `fric = fric_comp_pos/neg`（不用 Tc），**FF 库仑本就激活**（B 选项即当前机制）。0.5°/s 问题不在摩擦前馈缺失。

**0.5°/s 深挖结论（2026-08-17 追加）**：
- **非卡死，是慢**：0.5°/s 下位置环只给 ±0.03A（≈摩擦线），电机以 ~0.25°/s 爬（50%）。
- **非积分冻结**：实现 `CMD:POS_INTEGR_ERR`（条件积分阈值运行时化）扫 0.035→0.15 rad，**仍 51-54%**——阈值不是瓶颈。
- **根因 = 积分-摩擦极限环**：积分建立→过驱动→误差翻转→积分泄放→滞后→再积分的周期振荡，平均 50%。doc 3.7/3.8 已预见过（bang-bang 补偿死区在慢速斜坡失效）。
- **试遍 ki(0.2-1.5)/comp(0.022-0.10)/Stribeck/观测器D/积分阈值全部 ~50% 封顶**。
- **遗留**：0.5°/s 需架构级改动（位置环提频 / 摩擦前馈重构 / 正反向独立标定），当前 pos_direct 架构下是硬墙。接受画像：0.1°/s(95-101%) 强 + 2°/s(82%) 好，0.5°/s 缺口若实际云台慢摇 <0.2°/s 或快摇 >1°/s 可接受。
